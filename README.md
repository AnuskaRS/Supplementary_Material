# ISBI_2027_Supplementary_Material_Anuska

Cross-Modal and Motion-Compensated Spatial Reliability Estimation for Trustworthy Fluorescence-Guided Surgery:

This repository accompanies our research work on spatial reliability estimation for fluorescence-guided surgery (FGS). The proposed framework aims to improve the trustworthiness of fluorescence-based tissue segmentation by estimating pixel-wise prediction reliability under challenging intraoperative imaging conditions.

Supplementary Material: 

A supplementary video demonstrating the proposed framework is provided with this repository. The video illustrates the segmentation outputs and safety intraoperative guidance on an unseen Sentinel Lymph Node Dissection (SLND) procedure near the uterine wall.
